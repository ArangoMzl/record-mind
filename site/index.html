Cómo funciona

Cuatro columnas.
Tú solo capturas y apruebas.

01 Capturado

Lo capturas al vuelo

Atajo global, escribes la nota, pegas o arrastras la captura y Enter. El proyecto sale de la sesión activa de Claude Code.

$ record-mind add "No carga el logo" -i captura.png
02 Claude trabajando

Claude lo toma

Con /pendientes, Claude lee el tablero de tu proyecto por MCP, abre la tarea con sus capturas y la reclama.

> list_tasks() > claim_task(16)
03 Con memoria

Resuelve con Engram

Consulta las convenciones y decisiones del proyecto antes de tocar nada, y guarda lo que aprende para la próxima vez.

> mem_search("menú móvil") > mem_save(...)
04 Para revisar

Tú decides

Claude nunca marca nada como hecho. Te deja un resumen y los archivos que tocó; apruebas o devuelves con una nota.

$ record-mind approve 16 $ record-mind reopen 16 "falta en el footer"

Con Engram

Construido sobre Engram.
Sin tocar su base.

record-mind se apoya en Engram, la memoria persistente para agentes, para que cada pendiente se resuelva como se resuelven las cosas en tu proyecto.

  • Cada uno con su base

    Las tareas viven en record-mind.db, separadas de tus memorias.

  • Engram en solo lectura

    record-mind abre engram.db solo para saber qué sesión está activa, deducir el proyecto y sugerir memorias relacionadas.

  • Claude guarda lo aprendido

    Las memorias nuevas pasan por mem_save, a través de Engram, nunca escribiendo directo en su base.

Empieza

Deja de perder
los detalles.

Descarga el instalador, conéctalo con Claude Code y captura tu primer pendiente. Sin Rust, sin Node, sin compilar nada.

Descargar para Windows v0.1.0 · Windows 10/11 x64 · instalador .exe · 4,4 MB
1
Instala record-mindEjecuta el instalador. La app se queda en la bandeja del sistema, con el atajo y el MCP activos.
2
Conéctala a Claude Code (con la app abierta)$ claude mcp add --transport http -s user record-mind http://127.0.0.1:4545/mcp
3
Añade la skill /pendientesGuarda SKILL.md en ~/.claude/skills/pendientes/
4
Captura con Ctrl Shift Espacio y pídele a Claude que resuelva> /pendientes

El MCP vive dentro de la app: funciona mientras esté abierta o en la bandeja. Por ahora solo hay instalador para Windows.

¿Prefieres compilar desde el código?

Solo si quieres contribuir o probar la última versión. Requiere Rust (rustup), Node.js y, en Windows, Visual Studio Build Tools con «Desarrollo de escritorio con C++».

# CLI y servidor MCP por stdio → target/release/record-mind.exe $ cargo build --release # App de escritorio → instalador en target/release/bundle/nsis $ cd app && npm install && npm run tauri build # Opcional: MCP por stdio (Claude Code lo lanza solo, sin la app abierta) $ claude mcp add -s user record-mind -- record-mind mcp
